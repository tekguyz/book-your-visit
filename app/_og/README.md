# Fonts for drawn images

`ImageResponse` (the link preview, `app/opengraph-image.tsx`) cannot use `next/font` and cannot read WOFF2, so it reads these WOFF files. All are SIL Open Font License.

| File | Font | Source |
|---|---|---|
| `young-serif-400.woff` | Young Serif Regular | npm `@fontsource/young-serif`, `files/young-serif-latin-400-normal.woff` |
| `onest-400.woff` | Onest Regular | npm `@fontsource/onest`, `files/onest-latin-400-normal.woff` |
| `onest-600.woff` | Onest SemiBold | npm `@fontsource/onest`, `files/onest-latin-600-normal.woff` |
