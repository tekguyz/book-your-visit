# Fonts for drawn images

`ImageResponse` (the link preview, `app/opengraph-image.tsx`) cannot use `next/font` and cannot read WOFF2, so it reads these WOFF files. All are SIL Open Font License.

| File | Font | Source |
|---|---|---|
| `fraunces-700.woff` | Fraunces Bold | npm `@fontsource/fraunces`, `files/fraunces-latin-700-normal.woff` |
| `figtree-400.woff` | Figtree Regular | npm `@fontsource/figtree`, `files/figtree-latin-400-normal.woff` |
| `figtree-600.woff` | Figtree SemiBold | npm `@fontsource/figtree`, `files/figtree-latin-600-normal.woff` |
